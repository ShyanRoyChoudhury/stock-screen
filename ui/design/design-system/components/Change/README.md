# Change

A price change with a direction glyph.

- **Props:** `abs` (₹ change), `frac` (fractional change), `pct` (percent change), `showArrow`.
- Colour follows the sign, and there is always a ▲ ▼ ■ glyph so direction survives colour-blindness and greyscale.
- Use it in the symbol header and in last-close cells.
