# FilterChip

A filter in a toolbar.

- **Props:** `label`, `value`, `active`, `onClear`, `onClick` (opens your picker).
- An inactive chip is dashed ("+ Min R:R"). An active chip fills with `accent-soft` and shows its value in mono with a clear ×.
- Signals filters: strategy, timeframe, freshness, industry, max risk %, min R:R, conviction, entry mode.
