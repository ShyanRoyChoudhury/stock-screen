# Tabs

Tabs and segmented controls.

- **Props:** `items` (`[{id, label, count, experimental, title}]`), `value`, `onChange`, `variant` (`tabs` | `segmented`), `ariaLabel`.
- Use `tabs` for views (Open / Closed / By symbol) and `segmented` for modes (timeframe, density).
- Mark 1h and 4h with `experimental`.
