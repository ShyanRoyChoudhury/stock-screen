# NavRail

The main navigation: Today, Signals, Positions, Trades, Brokers and Data & Ops, then a reserved Derivatives section with Options disabled ("Later"), so options can be added later without restructuring. Settings and the account menu sit at the foot, so the layout doesn't assume a single user.

- **Props:** `items` (defaults to `NAV`), `current`, `counts` (red counters, e.g. positions needing action, failing brokers), `user`, `collapsed`, `onNavigate`.
- Hide the rail below 720px.
