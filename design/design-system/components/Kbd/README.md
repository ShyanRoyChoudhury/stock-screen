# Kbd

Keyboard hints. `keys` takes a space-separated sequence (`"g s"`) or an array (`["⌘","K"]`).

The shortcut map:
- `g t` / `g s` / `g p` / `g r` / `g b` / `g o` go to screens.
- `j`/`k` or arrows move the row cursor.
- `↵` expands a row.
- `/` searches for a symbol.

Show hints in the nav rail and on primary actions only.
