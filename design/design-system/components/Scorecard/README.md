# Scorecard

Confluence's four-part breakdown (Supertrend, MACD, BB position, volume) as ✓/✗ rows, plus room to the upper band and the conviction badge.

- **Props:** the signal's `details` spread in: `score`, `conviction`, `breakdown`.
- Pass `breakdown` strings verbatim from the API. The ✓ or ✗ inside each string decides pass or fail.
- Use it in the Signals row expand and in the side panel.
